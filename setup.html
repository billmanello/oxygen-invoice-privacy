🧾 Oxygen Invoice App — Οδηγός Εγκατάστασης

Το Oxygen Invoice App εκδίδει αυτόματα ΑΛΠ και ΤΠ για κάθε πληρωμένη παραγγελία στο Shopify σου και τα υποβάλλει στο myDATA της ΑΑΔΕ σε πραγματικό χρόνο.

Σημείωση: Ξεκίνα πάντα με το Sandbox περιβάλλον για δοκιμές. Μόνο αφού επιβεβαιώσεις ότι όλα δουλεύουν σωστά, πέρνα στο Production.
---

Βήμα 1 — Δημιουργία λογαριασμού στο Oxygen

Sandbox (δοκιμαστικό περιβάλλον)

  1. Πήγαινε στο https://sandbox-app.pelatologio.gr/register.php
  2. Δημιούργησε λογαριασμό με τα στοιχεία της επιχείρησής σου
  3. Ενημέρωσε το Oxygen support (support@oxygen.gr) με το email εγγραφής σου για να σου στείλουν το Sandbox API Key
Το sandbox περιβάλλον είναι καθαρά δοκιμαστικό — δεν αποστέλλονται πραγματικά emails και τα παραστατικά δεν υποβάλλονται στην ΑΑΔΕ.

Production (παραγωγικό περιβάλλον)

  1. Πήγαινε στο https://app.pelatologio.gr
  2. Δημιούργησε λογαριασμό με τα πραγματικά στοιχεία της επιχείρησής σου (ΑΦΜ, ΔΟΥ, κτλ.)
---

Βήμα 2 — Απόκτηση API Key

Το Oxygen δεν εκδίδει API Key αυτόματα — πρέπει να επικοινωνήσεις με το support τους:

  1. Στείλε email στο support@oxygen.gr
  2. Γράψε ότι θέλεις API Key για διασύνδεση Shopify eshop με το Oxygen
  3. Ζήτα Sandbox API Key αρχικά
  4. Θα σε ρωτήσουν το email εγγραφής σου στο sandbox — στείλτο
  5. Θα λάβεις το Sandbox API Key μέσω email
Μόλις τελειώσεις τις δοκιμές, επικοινώνησε ξανά για να λάβεις το Production API Key.
---

Βήμα 3 — Δημιουργία & Απόκτηση IDs από το Oxygen

Το app χρειάζεται 5 IDs από το Oxygen. Αυτά δεν φαίνονται στο UI — πρέπει πρώτα να δημιουργηθούν μέσα στην εφαρμογή και μετά να τα βγάλεις μέσω API.

Σημαντικό: Η παρακάτω διαδικασία γίνεται δύο φορές:
— Μία για το Sandbox περιβάλλον (δοκιμές) στο sandbox-app.pelatologio.gr
— Μία για το Production περιβάλλον (παραγωγή) στο app.pelatologio.gr

3α — Δημιουργία μέσα στο Oxygen (Sandbox)

Μπες στο sandbox-app.pelatologio.gr → κλικ γρανάζι ⚙️ → Πίνακας Ελέγχου και δημιούργησε τα παρακάτω:

Τι να δημιουργήσειςΟδηγίες
Σειρά Παραστατικών ΑΛΠ Πίνακας Ελέγχου → Σειρές Παραστατικών → Νέα σειρά → επέλεξε τύπο Απόδειξη Λιανικής Πώλησης (ΑΛΠ) → Αποθήκευσε
Σειρά Παραστατικών ΤΠ Πίνακας Ελέγχου → Σειρές Παραστατικών → Νέα σειρά → επέλεξε τύπο Τιμολόγιο Πώλησης (ΤΠ) → Αποθήκευσε
Default Επαφή (Contact) Επαφές → Νέα Επαφή → Συμπλήρωσε ένα γενικό όνομα π.χ. "Λιανικός Πελάτης" (χρησιμοποιείται για παραγγελίες χωρίς ΑΦΜ) → Αποθήκευσε
Τρόπος Πληρωμής Πίνακας Ελέγχου → Τρόποι Πληρωμής → Νέος → π.χ. "Κάρτα" ή "Μετρητά" → Αποθήκευσε
Συντελεστής ΦΠΑ 24% Πίνακας Ελέγχου → Συντελεστές ΦΠΑ → Νέος → βάλε 24% → Αποθήκευσε

3β — Απόκτηση Sandbox IDs μέσω API (με reqbin.com)

Πήγαινε στο reqbin.com. Σε κάθε κλήση πρόσθεσε header:

Authorization: Bearer ΤΟ_SANDBOX_API_KEY_ΣΟΥ

Numbering Sequence ID — ΑΛΠ & ΤΠ

GET https://sandbox-api.pelatologio.gr/v1/invoicing-series

Στο response θα δεις λίστα με τις σειρές που έφτιαξες. Βρες:

  • Τη σειρά τύπου ΑΛΠ → αντέγραψε το id → αυτό είναι το Numbering Sequence ID (ΑΛΠ)
  • Τη σειρά τύπου ΤΠ → αντέγραψε το id → αυτό είναι το Numbering Sequence ID (ΤΠ)

Contact ID

GET https://sandbox-api.pelatologio.gr/v1/contacts

Στο response βρες τον "Λιανικό Πελάτη" που έφτιαξες → αντέγραψε το id → αυτό είναι το Contact ID

Payment Method ID

GET https://sandbox-api.pelatologio.gr/v1/payment-methods

Στο response βρες τον τρόπο πληρωμής που έφτιαξες → αντέγραψε το id → αυτό είναι το Payment Method ID

Tax ID (ΦΠΑ 24%)

GET https://sandbox-api.pelatologio.gr/v1/taxes

Στο response βρες τον συντελεστή 24% → αντέγραψε το id → αυτό είναι το Tax ID

Κράτα τα 5 Sandbox IDs σε ένα αρχείο κειμένου — θα τα χρειαστείς στο Βήμα 4.

3γ — Δημιουργία μέσα στο Oxygen (Production)

Μόλις τελειώσεις τις δοκιμές στο Sandbox, επανάλαβε ακριβώς την ίδια διαδικασία για το Production:

Μπες στο app.pelatologio.gr → κλικ γρανάζι ⚙️ → Πίνακας Ελέγχου και δημιούργησε ξανά:

  • Σειρά Παραστατικών ΑΛΠ
  • Σειρά Παραστατικών ΤΠ
  • Default Επαφή "Λιανικός Πελάτης"
  • Τρόπος Πληρωμής
  • Συντελεστής ΦΠΑ 24%

3δ — Απόκτηση Production IDs μέσω API

Ίδια διαδικασία με 3β, αλλά με Production API Key και Production URLs:

Authorization: Bearer ΤΟ_PRODUCTION_API_KEY_ΣΟΥ
Τι θέλειςProduction URL
Numbering Sequences (ΑΛΠ & ΤΠ)GET https://api.pelatologio.gr/v1/invoicing-series
Contact IDGET https://api.pelatologio.gr/v1/contacts
Payment Method IDGET https://api.pelatologio.gr/v1/payment-methods
Tax ID (24%)GET https://api.pelatologio.gr/v1/taxes
Κράτα τα 5 Production IDs χωριστά από τα Sandbox IDs — θα τα χρειαστείς όταν περάσεις σε Production mode στο app.

Βήμα 4 — Ρύθμιση του app

  1. Άνοιξε το Oxygen Invoice App από το Shopify Admin σου
  2. Πήγαινε στις Ρυθμίσεις
  3. Επέλεξε Sandbox mode αρχικά
  4. Συμπλήρωσε τα παρακάτω πεδία:
ΠεδίοΤιμή
API KeyΤο Sandbox API Key που έλαβες από το Oxygen
Numbering Sequence ID (ΑΛΠ)Το id από το invoicing-series (ΑΛΠ)
Numbering Sequence ID (ΤΠ)Το id από το invoicing-series (ΤΠ)
Contact IDΤο id του γενικού πελάτη
Payment Method IDΤο id του τρόπου πληρωμής
Tax IDΤο id του ΦΠΑ 24%
  1. Πάτα Αποθήκευση
---

Βήμα 5 — Δοκιμή στο Sandbox

  1. Κάνε μια test παραγγελία στο Shopify σου
  2. Πήγαινε Dashboard στο app
  3. Θα εμφανιστεί νέο παραστατικό με status ✅ Success
  4. Αν δεις ❌ Failed → κλικ Retry ή έλεγξε ότι τα IDs είναι σωστά
---

Βήμα 6 — Μετάβαση σε Production

  1. Επικοινώνησε με το support@oxygen.gr για το Production API Key
  2. Πήγαινε Ρυθμίσεις → άλλαξε σε Production mode
  3. Συμπλήρωσε τα Production IDs (ίδια διαδικασία με Βήμα 3 αλλά με Production API Key και URL api.pelatologio.gr)
  4. Αποθήκευσε — από εδώ και πέρα κάθε πληρωμένη παραγγελία εκδίδει πραγματικό παραστατικό που υποβάλλεται αυτόματα στο myDATA
Προσοχή: Στο Production mode τα παραστατικά είναι νομικά δεσμευτικά και υποβάλλονται στην ΑΑΔΕ. Βεβαιώσου ότι όλα τα στοιχεία σου είναι σωστά πριν ενεργοποιήσεις.
---

Checkout — Έκδοση Τιμολογίου (ΤΠ)

Αν ο πελάτης σου θέλει τιμολόγιο αντί απόδειξης:

  • Στο checkout εμφανίζεται checkbox "Θέλω τιμολόγιο"
  • Ο πελάτης συμπληρώνει ΑΦΜ, Επωνυμία, ΔΟΥ
  • Το ΑΦΜ επαληθεύεται αυτόματα με MOD11 validation
  • Εκδίδεται αυτόματα ΤΠ αντί ΑΛΠ
