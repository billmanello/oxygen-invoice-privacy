🧾 Oxygen Invoice App — Οδηγός Εγκατάστασης

Το Oxygen Invoice App εκδίδει αυτόματα ΑΛΠ και ΤΠ για κάθε πληρωμένη παραγγελία στο Shopify σου και τα προωθεί στο Oxygen ERP, το οποίο αναλαμβάνει την υποβολή τους στο myDATA της ΑΑΔΕ.

Σημείωση: Ξεκίνα πάντα με το Sandbox περιβάλλον για δοκιμές. Μόνο αφού επιβεβαιώσεις ότι όλα δουλεύουν σωστά, πέρνα στο Production.
Εκδίδεις μόνο ΑΛΠ (λιανική); Τα Βήματα 5 και 6 (φόρμα τιμολογίου στο cart) είναι προαιρετικά. Αν δεν χρειάζεσαι έκδοση ΤΠ για επιχειρήσεις, μπορείς να τα παραλείψεις εντελώς. Επίσης, τα πεδία Numbering Sequence ID (ΤΠ) και Credit Note IDs στα Settings δεν είναι απαραίτητα.

Βήμα 1 — Δημιουργία λογαριασμού & Απόκτηση API Key

1α — Δημιουργία Production λογαριασμού (πρώτα αυτό)

  1. Πήγαινε στο https://app.pelatologio.gr
  2. Δημιούργησε λογαριασμό με τα πραγματικά στοιχεία της επιχείρησής σου (ΑΦΜ, ΔΟΥ, επωνυμία κτλ.)

1β — Επικοινωνία με το Oxygen support για API Keys

  1. Στείλε email στο support@oxygen.gr
  2. Γράψε ότι θέλεις API Key για διασύνδεση Shopify eshop με το Oxygen
  3. Θα σε ρωτήσουν αν θέλεις Sandbox ή Production — ζήτα αρχικά Sandbox
  4. Θα σου ζητήσουν να δημιουργήσεις λογαριασμό στο sandbox: https://sandbox-app.pelatologio.gr/register.php
  5. Δημιούργησε τον sandbox λογαριασμό και ενημέρωσε το support με το email εγγραφής σου
  6. Θα λάβεις το Sandbox API Key μέσω email
Το sandbox περιβάλλον είναι καθαρά δοκιμαστικό — δεν αποστέλλονται πραγματικά emails και τα παραστατικά δεν υποβάλλονται στην ΑΑΔΕ.
Μόλις τελειώσεις τις δοκιμές στο Sandbox, επικοινώνησε ξανά με το support για να λάβεις το Production API Key.

Βήμα 2 — Δημιουργία & Απόκτηση IDs από το Oxygen

Το app χρειάζεται 7 IDs από το Oxygen. Αυτά δεν φαίνονται στο UI — πρέπει πρώτα να δημιουργηθούν μέσα στην εφαρμογή και μετά να τα βγάλεις μέσω API.

Σημαντικό: Η παρακάτω διαδικασία γίνεται δύο φορές:
— Μία για το Sandbox περιβάλλον στο sandbox-app.pelatologio.gr
— Μία για το Production περιβάλλον στο app.pelatologio.gr

Μπες στο sandbox-app.pelatologio.gr → κλικ γρανάζι ⚙️ → Πίνακας Ελέγχου και δημιούργησε τα παρακάτω:

Βήμα 4 — Δοκιμή ΑΛΠ στο Sandbox

Για δοκιμή ΑΛΠ δεν χρειάζεται πραγματική πληρωμή. Χρησιμοποίησε Draft Order:

  1. Στο Shopify Admin πήγαινε Orders → Create order
  2. Πρόσθεσε ένα οποιοδήποτε προϊόν
  3. Κλικ "Mark as paid" — δεν απαιτείται πραγματική πληρωμή
  4. Πήγαινε στο Dashboard του app
  5. Θα εμφανιστεί νέο παραστατικό τύπου ΑΛΠ με status ✅ Success
  6. Αν δεις ❌ Failed → κλικ Retry ή έλεγξε ότι τα Sandbox IDs είναι σωστά
Η δοκιμή ΤΠ γίνεται στο Βήμα 6 — αφού πρώτα εγκατασταθεί το block στο cart (Βήμα 5).

Βήμα 5 — Ενεργοποίηση Φόρμας Τιμολογίου στο Cart

Προαιρετικό βήμα. Αν εκδίδεις αποκλειστικά ΑΛΠ, μπορείς να παραλείψεις τα Βήματα 5 και 6 εντελώς.

Η φόρμα για έκδοση τιμολογίου (ΤΠ) εμφανίζεται στη σελίδα καλαθιού (Cart Page) — όχι στο checkout και όχι στο cart drawer.

Σημαντικό: Το theme σου πρέπει να χρησιμοποιεί Cart Page και όχι Cart Drawer. Αν χρησιμοποιείς Cart Drawer, πρέπει πρώτα να το αλλάξεις σε Cart Page από τις ρυθμίσεις του theme.

5α — Έλεγξε ότι χρησιμοποιείς Cart Page

  1. Στο Shopify Admin πήγαινε Online Store → Themes
  2. Κλικ Customize στο ενεργό theme σου
  3. Από το αριστερό menu επέλεξε Cart
  4. Βεβαιώσου ότι ο τύπος καλαθιού είναι Page και όχι Drawer
  5. Αν είναι Drawer → άλλαξέ το σε Page → Save

5β — Πρόσθεσε το block της φόρμας τιμολογίου

  1. Στο Shopify Admin πήγαινε Online Store → Themes
  2. Κλικ Customize στο ενεργό theme σου
  3. Από το dropdown πάνω κεντρικά επέλεξε Cart (Cart Page)
  4. Στο αριστερό panel βρες την ενότητα του cart (συνήθως "Cart items" ή "Main cart")
  5. Κλικ "Add block"
  6. Βρες και επέλεξε το block "Oxygen Invoice Fields"
  7. Κλικ Save
Αν το block "Oxygen Invoice Fields" δεν εμφανίζεται στη λίστα, βεβαιώσου ότι το Oxygen Invoice App είναι εγκατεστημένο και ενεργό στο Shopify Admin σου.

Πώς λειτουργεί η φόρμα τιμολογίου

  • Στη σελίδα καλαθιού εμφανίζεται section "Έκδοση Τιμολογίου"
  • Ο πελάτης συμπληρώνει ΑΦΜ, Επωνυμία, ΔΟΥ
  • Το ΑΦΜ επαληθεύεται αυτόματα με MOD11 validation
  • Αν συμπληρωθεί έγκυρο ΑΦΜ και ολοκληρωθεί η παραγγελία → εκδίδεται αυτόματα ΤΠ αντί ΑΛΠ
  • Αν τα πεδία μείνουν κενά → εκδίδεται κανονικά ΑΛΠ

Απεγκατάσταση app — Σημαντική σημείωση

Αν απεγκαταστήσεις το Oxygen Invoice App, το Shopify δεν αφαιρεί αυτόματα το block από το theme σου. Το block παραμένει ορφανό και εμφανίζεται κενό στη σελίδα καλαθιού.

Για να το αφαιρέσεις χειροκίνητα:
  1. Πήγαινε Online Store → Themes → Customize
  2. Επέλεξε Cart (Cart Page)
  3. Βρες το block "Oxygen Invoice Fields" στο αριστερό panel
  4. Κλικ πάνω του → Remove block
  5. Κλικ Save
Αν επανεγκαταστήσεις το app, πρέπει να προσθέσεις ξανά το block από την αρχή (Βήμα 5β).

Βήμα 6 — Δοκιμή ΤΠ στο Sandbox

Τώρα που έχει εγκατασταθεί το block, κάνε δοκιμή ΤΠ. Απαιτείται κανονική ροή παραγγελίας μέσω checkout — για να μην γίνει πραγματική χρέωση ενεργοποίησε το Test mode:

  1. Στο Shopify Admin πήγαινε Settings → Payments
  2. Ενεργοποίησε το Test mode (Bogus Gateway ή Shopify Payments test mode)
  3. Πήγαινε στο κατάστημά σου → πρόσθεσε προϊόν στο καλάθι
  4. Στη σελίδα καλαθιού συμπλήρωσε ΑΦΜ, Επωνυμία, ΔΟΥ στη φόρμα τιμολογίου
  5. Ολοκλήρωσε την παραγγελία με δοκιμαστική κάρτα (π.χ. 4242 4242 4242 4242)
  6. Πήγαινε στο Dashboard του app
  7. Θα εμφανιστεί νέο παραστατικό τύπου ΤΠ με status ✅ Success
Μετά τις δοκιμές απενεργοποίησε το Test mode από Settings → Payments πριν πας σε Production.

Βήμα 7 — Μετάβαση σε Production

  1. Βεβαιώσου ότι έχεις απενεργοποιήσει το Test mode από Settings → Payments
  2. Επικοινώνησε με το support@oxygen.gr για το Production API Key (αν δεν το έχεις ήδη)
  3. Πήγαινε στις Ρυθμίσεις του app → άλλαξε σε Production mode
  4. Συμπλήρωσε τα Production IDs και το Production API Key (από το Βήμα 2γ/2δ)
  5. Πάτα Αποθήκευση

Δοκιμαστική παραγγελία σε Production

Πριν αρχίσεις κανονικά, κάνε μία δοκιμαστική παραγγελία για να επιβεβαιώσεις ότι όλα λειτουργούν:

  1. Δημιούργησε ένα δοκιμαστικό προϊόν με τιμή €1,00 (ή χρησιμοποίησε υπάρχον με χαμηλή τιμή)
  2. Για δοκιμή ΑΛΠ: κάνε παραγγελία χωρίς συμπλήρωση ΑΦΜ στο cart
  3. Για δοκιμή ΤΠ: κάνε παραγγελία με συμπλήρωση ΑΦΜ στη φόρμα του cart
  4. Πήγαινε στο Dashboard του app και επιβεβαίωσε ότι εμφανίζεται ✅ Success
  5. Κλικ "Άνοιγμα" και επιβεβαίωσε ότι το παραστατικό υπάρχει στο Oxygen production dashboard
Προσοχή: Στο Production mode τα παραστατικά είναι νομικά δεσμευτικά και υποβάλλονται αυτόματα στην ΑΑΔΕ. Βεβαιώσου ότι όλα τα στοιχεία της επιχείρησής σου (ΑΦΜ, ΔΟΥ, σειρές παραστατικών) είναι σωστά πριν ενεργοποιήσεις.
