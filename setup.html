🧾 Oxygen Invoice App — Οδηγός Εγκατάστασης

Το Oxygen Invoice App εκδίδει αυτόματα ΑΛΠ και ΤΠ για κάθε πληρωμένη παραγγελία στο Shopify σου και τα υποβάλλει στο myDATA της ΑΑΔΕ σε πραγματικό χρόνο.

Βήμα 1 — Δημιουργία λογαριασμού στο Oxygen

Αν δεν έχεις ήδη λογαριασμό:

  1. Πήγαινε στο oxygen.gr
  2. Δημιούργησε λογαριασμό επιχείρησης
  3. Συμπλήρωσε τα στοιχεία της επιχείρησής σου (ΑΦΜ, ΔΟΥ, κτλ.)

Βήμα 2 — Απόκτηση API Key

  1. Σύνδεσου στο Oxygen
  2. Πήγαινε Ρυθμίσεις → API Key
  3. Αντέγραψε το API Key

Βήμα 3 — Απόκτηση IDs από το Oxygen

Χρειάζεσαι 4 IDs:

ΠεδίοΠού το βρίσκεις
Numbering Sequence ID (ΑΛΠ)Ρυθμίσεις → Αρίθμηση → ΑΛΠ
Numbering Sequence ID (ΤΠ)Ρυθμίσεις → Αρίθμηση → ΤΠ
Contact IDΕπαφές → Default πελάτης → ID
Payment Method IDΡυθμίσεις → Τρόποι πληρωμής → ID

Βήμα 4 — Ρύθμιση του app

  1. Άνοιξε το Oxygen Invoice App από το Shopify Admin
  2. Πήγαινε Ρυθμίσεις
  3. Επέλεξε Production mode
  4. Συμπλήρωσε: API Key, Numbering Sequence IDs, Contact ID, Payment Method ID
  5. Πάτα Αποθήκευση

Βήμα 5 — Επαλήθευση

  1. Κάνε μια test παραγγελία στο Shopify σου
  2. Πήγαινε Dashboard στο app
  3. Θα πρέπει να εμφανιστεί νέο παραστατικό με status ✅

Checkout — Έκδοση Τιμολογίου (ΤΠ)

Στο checkout εμφανίζεται checkbox "Θέλω τιμολόγιο". Ο πελάτης συμπληρώνει ΑΦΜ, Επωνυμία, ΔΟΥ και εκδίδεται αυτόματα ΤΠ αντί ΑΛΠ.
